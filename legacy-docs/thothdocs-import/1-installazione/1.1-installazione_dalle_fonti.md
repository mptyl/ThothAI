# Installation from Source

This method is designed for **developers**, **contributors**, or anyone who needs deep customization of the code or Docker images.

## 1. Prerequisites

Make sure you have installed:
*   **Git**: To clone the repository.
*   **Docker Desktop** (Mac/Windows) or **Docker Engine** (Linux): Active and running.
*   **Python 3.9+** (optional but recommended for utility scripts).
*   **uv** (optional, recommended for Python package management).

### Note for Windows users
If you are using Windows, make sure **WSL 2** is enabled and configured with Docker Desktop. Shell commands (`.sh`) must be executed in WSL, while PowerShell scripts (`.ps1`) can be executed directly from Windows PowerShell.

## 2. Repository Cloning

Download the complete source code:

```bash
git clone https://github.com/mptyl/ThothAI.git
cd ThothAI
```

## 3. Configuration

Before starting, you need to create and modify the local configuration file.

1.  Copy the template:
    *   **Mac/Linux:** `cp config.yml config.yml.local`
    *   **Windows:** `Copy-Item config.yml config.yml.local`

2.  Edit `config.yml.local` entering:
    *   Your **API Keys** (OpenAI, Anthropic, Gemini, etc.).
    *   Any configuration overrides (ports, databases, etc.).

> [!IMPORTANT]
> Never commit `config.yml.local` or `.env` files containing secrets!

## 4. Quick Installation and Startup

Automatic installation scripts are provided to manage Docker environment creation, image downloads, and startup.

### Mac/Linux
Run the bash script:
```bash
./install.sh
```

### Windows
Run the PowerShell script (from Windows PowerShell):
```powershell
.\install.ps1
```

The script will execute:
1.  Verification of `config.yml.local`.
2.  Generation of environment files (e.g. `.env.docker`).
3.  Pull or Build of images.
4.  Startup of services (`docker compose up`).

## 5. Custom Build and Push (Advanced)

If you have modified the code and want to distribute your custom images (instead of using the official `tylconsulting` ones), you need to build and push to your registry.

### Requirements for Push
*   Docker Hub account (or other registry).
*   Write access to the registry (run `docker login`).

### Using `push.sh`

The `push.sh` script automates multi-architecture build and push.

```bash
# Syntax: ./push.sh <REGISTRY_URL> <VERSION> [OPTIONS]

# Example: Push to personal Docker Hub (user 'myuser'), version 1.0
./push.sh docker.io/myuser 1.0
```

This will create and upload the images (e.g. `docker.io/myuser/thoth-backend:1.0` and `:latest`).

#### Custom Registry Configuration
After the push, update `config.yml.local` to use your new images:

```yaml
docker:
  image_registry: "myuser" # Your registry namespace
  # If it's a private registry, add username/password here
```

Then re-run `./install.sh` to update the running stack.

## 6. Using the CLI from Source

The repository includes the source code for `thothai-cli`. You can use it directly without installing via pip, useful for testing changes to the CLI itself.

```bash
# Example: Running the 'up' command using uv
uv run thothai up
```

For more details on available commands, consult the manuals [3_CLI_COMPOSE_INSTALLATION.md](3_CLI_COMPOSE_INSTALLATION.md) and [4_CLI_SWARM_INSTALLATION.md](4_CLI_SWARM_INSTALLATION.md) and [5_CLI_MANAGEMENT.md](5_CLI_MANAGEMENT.md).

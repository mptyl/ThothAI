# Installazione dalle Fonti

Questa modalità è progettata per **sviluppatori**, **contributori**, o chiunque necessiti di personalizzazioni profonde del codice o delle immagini Docker.

## 1. Prerequisiti

Assicurati di aver installato:
*   **Git**: Per clonare il repository.
*   **Docker Desktop** (Mac/Windows) o **Docker Engine** (Linux): Attivo e in esecuzione.
*   **Python 3.9+** (opzionale ma consigliato per script di utilità).
*   **uv** (opzionale, consigliato per la gestione dei pacchetti Python).

### Nota per utenti Windows
Se stai utilizzando Windows, assicurati che **WSL 2** sia abilitato e configurato con Docker Desktop. I comandi della shell (`.sh`) devono essere eseguiti in WSL, mentre gli script PowerShell (`.ps1`) possono essere eseguiti direttamente da Windows PowerShell.

## 2. Clonazione del Repository

Scarica il codice sorgente completo:

```bash
git clone https://github.com/mptyl/ThothAI.git
cd ThothAI
```

## 3. Configurazione

Prima di iniziare, devi creare e modificare il file di configurazione locale.

1.  Copia il template:
    *   **Mac/Linux:** `cp config.yml config.yml.local`
    *   **Windows:** `Copy-Item config.yml config.yml.local`

2.  Modifica `config.yml.local` inserendo:
    *   Le tue **API Keys** (OpenAI, Anthropic, Gemini, ecc.).
    *   Eventuali override di configurazione (porte, database, ecc.).

> [!IMPORTANT]
> Non commettere mai i file `config.yml.local` o `.env` contenenti segreti!

## 4. Installazione e Avvio Rapido

Sono forniti script di installazione automatici per gestire la creazione dell'ambiente Docker, il download delle immagini e l'avvio.

### Mac/Linux
Esegui lo script bash:
```bash
./install.sh
```

### Windows
Esegui lo script PowerShell (da Windows PowerShell):
```powershell
.\install.ps1
```

Lo script eseguirà:
1.  Verifica di `config.yml.local`.
2.  Generazione dei file environment (es. `.env.docker`).
3.  Pull o Build delle immagini.
4.  Avvio dei servizi (`docker compose up`).

## 5. Build Personalizzato e Push (Avanzato)

Se hai modificato il codice e vuoi distribuire le tue immagini personalizzate (invece di usare quelle ufficiali `tylconsulting`), devi fare il build e push verso il tuo registry.

### Requisiti per il Push
*   Account Docker Hub (o altro registry).
*   Accesso in scrittura al registry (esegui `docker login`).

### Utilizzo di `push.sh`

Lo script `push.sh` automatizza il build e push multi-architettura.

```bash
# Sintassi: ./push.sh <REGISTRY_URL> <VERSIONE> [OPZIONI]

# Esempio: Push verso Docker Hub personale (utente 'myuser'), versione 1.0
./push.sh docker.io/myuser 1.0
```

Questo creerà e caricherà le immagini (es. `docker.io/myuser/thoth-backend:1.0` e `:latest`).

#### Configurazione Registry Personalizzato
Dopo il push, aggiorna `config.yml.local` per utilizzare le tue nuove immagini:

```yaml
docker:
  image_registry: "myuser" # Il tuo namespace del registry
  # Se è un registry privato, aggiungi username/password qui
```

Poi riesegui `./install.sh` per aggiornare lo stack in esecuzione.

## 6. Utilizzo della CLI dalle Fonti

Il repository include il codice sorgente per `thothai-cli`. Puoi utilizzarlo direttamente senza installare via pip, utile per testare modifiche alla CLI stessa.

```bash
# Esempio: Esecuzione del comando 'up' utilizzando uv
uv run thothai up
```

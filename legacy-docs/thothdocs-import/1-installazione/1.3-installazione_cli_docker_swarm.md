# CLI Installation on Docker Swarm (Cluster)

This guide explains how to install ThothAI on a **Docker Swarm** cluster. This is the recommended mode for production, high reliability, and scalability.

## 1. Prerequisites

*   **Swarm Cluster**: Target server with Docker Engine initialized as Swarm Manager (`docker swarm init`).
*   **Python 3.9+** and **uv** installed on the management machine (from where you will launch the commands).
*   **SSH Access** to the cluster manager node.

## 2. Swarm Initialization

In your project folder, initialize the configuration for Swarm:

```bash
uv run thothai init --mode swarm
```

This will generate:
*   `config.yml.local`: Main configuration.
*   `swarm_config.env`: Variables specific to the Swarm stack.
*   `.env.docker`: Auto-generated environment file.

## 3. Configuration

Modify `config.yml.local`. The `docker` section is crucial for telling the cluster where to download images from.

```yaml
docker:
  network_name: "thoth-network"
  # Default: Public Docker Hub (tylconsulting)
  # image_registry: "tylconsulting" 
  
  # Optional: Private Registry (Uncomment if necessary)
  # image_registry: "registry.company.com/my-company"
  # registry_username: "user"
  # registry_password: "password"
```

## 4. Deploy on Swarm

The `swarm deploy` command handles transferring configurations and starting the stack. Usually you operate towards a remote server (the cluster manager).

```bash
uv run thothai swarm deploy --server ssh://manager-node-user@ip
```

### What happens during deployment
1.  **Connection**: The CLI connects via SSH to the manager node.
2.  **Authentication**: If a private registry is configured, it performs login on all nodes (or manages authentication via `--with-registry-auth`).
3.  **Configuration**: Creates/updates Docker Secrets and Configs.
4.  **Startup**: Executes `docker stack deploy`.

## 5. Verification

Verify that services are distributed and active:

```bash
uv run thothai swarm status --server ssh://manager-node-user@ip
```

You should see a list of services with replicas `1/1` (or more if scaled).

## 6. Update

To update the cluster (e.g. after changing version in `config.yml` or after a new image push):

```bash
uv run thothai swarm deploy --server ssh://manager-node-user@ip
```

The command is idempotent: it will update only the necessary services.

# Logfire: Observability Service for Python Applications

Logfire is an observability platform built by Pydantic that simplifies monitoring, debugging, and analyzing Python applications via distributed tracing, structured logging, and metrics. It provides a “batteries-included” solution for full visibility without complex configuration.

## Key features

**Distributed tracing**: Logfire uses OpenTelemetry to automatically trace HTTP requests, database calls, LLM interactions, and more. Each span captures timing details, contextual attributes, and relationships between services, letting you follow a full request across components.

**Structured logging**: It offers an advanced logging system for recording events with structured attributes, making it easy to analyze logs through SQL queries or visual interfaces.

**LLM/AI support**: Logfire includes specialized tooling to monitor large-language-model interactions (OpenAI, Anthropic, Gemini, etc.), tracking prompts, responses, and token usage.

## Debugging with Logfire

Logfire provides powerful debugging tools:

1. **Trace Explorer**: A web UI to browse traces in real time, inspect service relationships, and analyze performance.
2. **SQL queries**: Ability to run SQL directly on trace data for custom analyses.
3. **Alerting**: Configure smart alerts based on metrics, errors, or specific conditions.

**Demo video**: The official documentation’s “Debugging” chapter at [https://ai.pydantic.dev/logfire/](https://ai.pydantic.dev/logfire/) contains a tutorial showing how to use the Logfire UI to identify and resolve issues by analyzing traces and logs.

## Usage examples in ThothSL

In ThothSL, Logfire is used to monitor and trace operations in multiple contexts:

**Monitoring AI agents**: Each time an AI agent processes a user request, Logfire traces the entire flow—from receiving the request, through context analysis, to generating the final response.

**Logging validations**: When data is validated or processed, Logfire records every step, highlighting validation errors or data issues.

These tools provide a complete, real-time view of application behavior, making it easy to spot bottlenecks or malfunctions quickly.

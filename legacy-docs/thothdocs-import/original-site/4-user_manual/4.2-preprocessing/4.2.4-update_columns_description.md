# Updating Column Descriptions

The **Update Column Descriptions** feature in the ThothAI backend lets you refresh column metadata for the database tied to a workspace. It’s useful for keeping field descriptions up to date, especially when working with databases that require detailed metadata (e.g., BIRD datasets).

## 1 - What happens when you click “Update Column Descriptions”

Clicking the button in the preprocessing area starts a process that updates column metadata for the database configured in the current workspace. The system reads from specific CSV files—organized by database name and mode (dev, test, prod)—and applies those descriptions directly to the database.

During the operation, a loading spinner provides visual feedback. When finished, a confirmation message appears showing success plus the date/time of the latest update.

## 2 - Information loaded

The process loads:
- column names (updated if necessary);
- column descriptions explaining the meaning or usage of each field;
- value descriptions giving extra detail about the column’s data.

These data come from predefined CSV files structured to match the database tables, ensuring the information maps onto the correct columns.

## 3 - How columns are updated

In the ThothAI backend (shared with ThothSL), column records are updated by matching CSV entries to existing database columns. When a match is found, the column metadata is overwritten with the new information. This keeps descriptions accurate and aligned with the latest database specs, helping both backend and ThothSL users understand the data.

## 4 - UI area responsible for the update

The **Preprocessing** section of the backend UI exposes this feature. A dedicated button (“Update Column Descriptions”) starts the process. The interface displays the date of the last update (or a “never run” message). During processing, a spinner shows progress, and success/error messages appear at the end, providing clear feedback.

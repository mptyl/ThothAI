# Loading Evidence into ThothAI

## 1 - What Evidence are

**Evidence** in ThothAI are short natural-language hints that add useful context to a digital workspace for better data management and analysis. They capture important details that make it easier to understand and use the available information.

## 2 - Why Evidence are loaded

Uploading Evidence is essential to improve the quality of information available. They serve several key purposes:

- **Provide additional context**: They clarify data or requests, improving the quality of answers or results.
- **Support user requests**: They offer helpful directions for better interpreting user questions or operations.
- **Keep the workspace up to date**: With fresh Evidence, the system stays current and ready to address user needs effectively.

Therefore, loading Evidence is a key step in preparing the workspace to handle requests more easily and helpfully.

## 3 - How Evidence are loaded

### 3.1 - Internal processing

Evidence are collected from predefined sources and automatically added to the workspace. If there are existing records, they are replaced with the latest entries to keep everything up to date. Once loaded, the workspace logs the update to know when the last change was made.

On top of that, admins can create new Evidence, edit or delete them individually or in bulk, and export/import them via files for easy sharing.

### 3.2 - User interface

In the ThothAI UI, Evidence appear in a clear table where each hint is listed with its content. Users with the proper permissions can:

- **Add an Evidence**: Create a new hint and insert it in the table.
- **Edit an Evidence**: Update the content of an existing hint.
- **Delete an Evidence**: Remove a hint, with confirmation to avoid mistakes.
- **Delete all Evidence**: Remove every hint at once (with a safety check).
- **Save or import Evidence**: Export hints to a file or import new ones from an existing file.

If no Evidence are available or a load issue occurs, the UI shows a clear message.

## 4 - Using Evidence to drive data requests

### 4.1 - Process overview

In ThothAI, Evidence are extremely helpful when turning a question or request into a concrete data action (like retrieving information from a database). The system leverages Evidence to interpret user requests through the implemented SQL-generation pipeline:

1. **Retrieved-context approach**: The system validates the request, extracts keywords, retrieves Evidence and similar SQL, narrows the schema, and generates candidate queries that are later tested and evaluated.

### 4.2 - The role of Evidence

Evidence provide extra context that helps the system better understand user requests. They guide the interpretation, making responses more accurate and relevant. If something goes wrong, Evidence also help pinpoint where the issue lies, simplifying troubleshooting.

In summary, loading Evidence in ThothAI combines automated management with a straightforward UI, enabling intuitive organization of hints. Evidence are fundamental for turning requests into effective data actions, ensuring the workspace is always ready with updated, relevant context.

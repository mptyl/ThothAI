# Questions (Gold SQL)

## 1 - Introduction

**Questions** are a central element in ThothSL, which uses AI to turn natural-language input into executable SQL queries. This lets users query databases without knowing SQL, making data access more intuitive.

## 2 - Purpose of Questions in ThothSL

In ThothSL, Questions are user inputs phrased in natural language. The goal is to interpret each question and automatically generate the SQL needed to retrieve the requested information. For example: “What is the average revenue per customer?” is analyzed and translated into the SQL that calculates it.

The system uses AI agents to analyze the question text, extract keywords, retrieve relevant context and hints from the vector database, and finally produce a valid SQL query. This approach handles even complex questions, ensuring accurate, relevant results.

## 3 - Information stored with Questions

Every Question in the system includes:

- **Question text**: The natural-language text entered by the user.
- **Generated SQL**: The SQL produced in response, which can be executed on the database to obtain the requested data.
- **Hint**: Optional text providing extra context or directions, improving SQL generation accuracy.

This information is stored as an `SqlDocument` in the vector database, allowing fast, organized access.

## 4 - Loading Questions in the ThothAI backend

The ThothAI backend (which shares the vector DB with ThothSL) handles loading and storing Questions through a structured process:

- **Vector database**: Questions are stored in a vector DB, enabling semantic search and retrieval of similar examples or hints during SQL generation.
- **Loading process**: Users can upload Questions via a dedicated interface. Specialized functions read data (e.g., from CSV files) and insert it into the vector DB, updating workspace metadata with the time of the last operation.
- **Question management**: The backend lets you create, edit, and delete Questions so the vector DB stays current and aligned with user needs.

## 5 - Interaction with the ThothAI UI

The ThothAI UI makes Question management simple and intuitive:

- **Viewing Questions**: A dedicated section (`questions.html`) lists the Questions in the vector DB. Users can see the question text, generated SQL, and any associated hints.
- **Uploading and managing**: Buttons and forms let users upload new Questions, edit existing ones, or delete them. For example, a “Upload Questions” button triggers the process, while specific forms let you enter or update individual Question details.
- **User feedback**: During uploads or edits, the UI provides immediate feedback (confirmation messages, error alerts) so users always know the status of their actions.

In short, Questions are the entry point for user interaction with Thoth, turning natural-language requests into executable SQL thanks to advanced AI and vector-database infrastructure. Managing them through the backend and UI ensures a smooth, functional experience.

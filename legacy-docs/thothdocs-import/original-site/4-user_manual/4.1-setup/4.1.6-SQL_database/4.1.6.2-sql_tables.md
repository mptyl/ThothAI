# SQL Tables

This document describes the metadata related to SQL tables managed within the ThothAI system. Metadata are structured pieces of information that describe tables and make data management and querying easier.

## 1 - SqlTable Model

### 1.1 - Description
The `SqlTable` model represents a table inside an SQL database. It catalogs the tables available for querying.

- **Key fields**:
  - **Name**: Table name.
  - **Description**: Textual description of the table and its purpose.
  - **Generated comment**: Comments automatically produced (often via AI) to describe the table.
  - **SQL database**: Reference to the `SqlDb` this table belongs to.

- **Relationships**:
  - A `SqlTable` belongs to one `SqlDb`.
  - It can contain multiple `SqlColumn` entries representing its columns.
  - It participates in `Relationship` records as source or target table to define table relationships.

## 2 - Model Usage in ThothSL

Within the ThothSL project, the `SqlTable` model organizes and exposes table information during SQL generation. Main functions include:

- **Database schema retrieval**: The system extracts table structures to understand the available data.
- **Schema string generation**: Table information is converted into textual representations optimized for LLM prompts.
- **Schema filtering**: Only tables relevant to a specific query or context are selected, reducing complexity.

## 3 - Associated Administration Form

### 3.1 - SqlTableAdmin
The admin form for `SqlTable` lets you view and update information about the database tables.

- **Features**:
  - View and edit table name/description.
  - Generate comments for the table via AI.
  - Create columns for the table.
  - Validate primary/foreign key fields.
  - Copy generated comments into the description.

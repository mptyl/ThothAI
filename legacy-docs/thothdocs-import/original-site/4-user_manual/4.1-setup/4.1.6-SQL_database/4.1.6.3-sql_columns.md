# SQL Columns

This document describes the metadata for SQL columns managed within the ThothAI system. These structured details make column management and querying easier.

## 1 - SqlColumn Model

### 1.1 - Description
The `SqlColumn` model represents a specific column inside a table of an SQL database. This level of detail is essential for understanding the data structure.

- **Key fields**:
  - **Original column name**: The original column name in the database.
  - **Column name**: Expanded or clarified name, if needed.
  - **Data type**: e.g. INT, VARCHAR, DATE.
  - **Column description**: Textual explanation of the column’s content or purpose.
  - **Generated comment**: Optional AI-generated comments.
  - **Value description**: Information about typical values or their meaning.
  - **PK flag**: Indicates if the column is a primary key.
  - **FK flag**: Indicates if the column is a foreign key and which table/column it points to.
  - **SQL table**: Reference to the `SqlTable` owning this column.

- **Relationships**:
  - A `SqlColumn` belongs to one `SqlTable`.
  - It can participate in `Relationship` records as source or target column to define foreign-key links.

## 2 - Model Usage in ThothAI

In the ThothAI project, the `SqlColumn` model provides detailed column information when generating SQL. Main functions include:

- **Database schema retrieval**: Extracts column structures to understand available data.
- **Schema string generation**: Converts column info into textual forms optimized for LLM prompts.
- **Schema filtering**: Selects only columns relevant to a specific query or context.
- **Value examples**: Adds sample values (when available) to give additional context.

## 3 - Associated Administration Form

### 3.1 - SqlColumnAdmin
The admin form for `SqlColumn` manages the column details inside tables.

- **Features**:
  - Edit original and expanded column name.
  - Set the data type.
  - Enter descriptions and generated comments.
  - Flag primary/foreign keys.
  - Generate comments for selected columns via AI.
  - Copy names/comments between fields.

# SQL Database

This user manual provides an overview of the SQL database management system inside the ThothAI backend. It explains how to configure, manage and use SQL databases to support the system’s capabilities.

## 1 - Introduction to SQL Databases in ThothAI

The ThothAI backend offers an advanced system for SQL database management, allowing users to configure and administer many types of relational databases. It is designed to integrate with other backend components, simplifying data access and processing.

### 1.1 - Purpose of the SQL Database Management System

ThothAI’s SQL database management system aims to provide an intuitive interface for configuration and administration. Users can define database connections, manage tables and columns, and establish relationships through a user-friendly admin interface.

### 1.2 - Types of Databases Supported

ThothAI supports a wide range of SQL databases, including PostgreSQL, MySQL, MariaDB, Oracle, SQL Server and SQLite. This lets teams adopt the database best aligned with their requirements while preserving flexibility and compatibility.

## 2 - Configuring a SQL Database

SQL databases are configured through an admin form that collects all the information needed to connect to and manage the database.

### 2.1 - Basic Information

- **Database name**: Unique identifier inside Thoth.
- **Database type**: Drop-down selection (PostgreSQL, MySQL, etc.) that determines provider-specific options.
- **Host**: Address of the server hosting the database.
- **Database name on server**: Actual DB name in the RDBMS.
- **Schema**: (Optional) schema used inside the database.
- **Port**: Connection port.
- **Credentials**: Username/password to access the database.
- **Mode**: Indicates whether the DB is used for development, testing or production.

### 2.2 - Integration with Vector Databases

Every SQL database can be associated with a vector database, enabling advanced semantic search and analysis. This integration combines structured SQL data with vector-search capabilities.

### 2.3 - Advanced Settings

- **Language**: Language used for data and metadata, useful when generating localized content.
- **Scope**: Text description of the database scope/context, either generated automatically or supplied manually.

## 3 - Managing Tables and Columns

Once the database is configured, you can manage the tables and columns holding your data.

### 3.1 - Creating and Managing Tables

Tables are the primary entities inside the SQL database. ThothAI lets you create them automatically or manually, with options for:

- **Table name**
- **Description**: Purpose/content of the table.
- **Generated comment**: Auto-created description (often via AI) that can be copied into the description field.

### 3.2 - Creating and Managing Columns

Columns define the data fields within each table. For each column you can set:

- **Original column name**: As stored in the DB.
- **Column name**: Optional friendly name.
- **Data type**.
- **Column description**.
- **Generated comment** (optional AI-generated text).
- **Value description**: Extra info about the meaning of values.
- **Primary key** flag.
- **Foreign key** flag.

## 4 - Relationships between Tables

ThothAI allows you to define relationships between tables to represent data links.

### 4.1 - Relationship Configuration

Relationships are defined by specifying a source table/column and a destination table/column. This establishes foreign-key style links.

### 4.2 - Key Field Updates

After defining a relationship you can automatically update primary/foreign key fields on the involved columns, streamlining dependency management.

## 5 - Available Administrative Actions

The admin UI offers several actions to manage SQL databases efficiently.

### 5.1 - Data Export and Import

- **Export to CSV**: Export database/table/column/relationship data for backup or offline analysis.
- **Import from CSV**: Populate or update the database from CSV files.
- **Export database structure**: Export the full structure for documentation or migration.

### 5.2 - AI-Assisted Comment Generation

- **Table comment generation**: AI-generated descriptions for tables based on their content.
- **Column comment generation**: AI-generated column descriptions ready to copy into official fields.

### 5.3 - Foreign Key Field Validation

- **Database-level validation**: Checks that all foreign-key references are valid.
- **Table-level validation**: Runs FK checks on selected tables.
- **Column-level validation**: Ensures FK fields are correctly formatted for specific columns.

### 5.4 - Invalid Key Field Cleanup

- **Invalid key-field cleanup**: Removes or corrects invalid primary/foreign key values in selected tables.

### 5.5 - Copying Generated Comments

- **Copy generated comments**: Moves AI-generated comments into the official description fields (when non-empty).

### 5.6 - Column Name Management

- **Column name copy**: Syncs the friendly name from/to the original DB name.

### 5.7 - Database Object Creation

- **Create tables**: Auto-builds tables for a selected database using available metadata.
- **Create columns**: Populates table columns accordingly.
- **Create relationships**: Identifies and adds relationships based on data and foreign keys.
- **Complete creation**: Runs the full table/column/relationship creation workflow.

### 5.8 - Database Scope Generation

- **Scope generation**: Produces a textual description of the database scope/context.

## 6 - Conclusion

The SQL database management system in the ThothAI backend simplifies configuration, administration, and day-to-day use of relational databases. With an intuitive interface and a rich set of admin actions, users can keep their data well-structured and accessible for all system needs.

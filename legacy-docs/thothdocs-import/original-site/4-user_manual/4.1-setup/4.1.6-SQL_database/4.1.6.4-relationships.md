# SQL Relationships

This document describes the metadata for SQL relationships managed within the ThothAI system. These structured details describe how tables are linked and make it easier to manage and query data.

## 1 - Relationship Model

### 1.1 - Descrizione
The `Relationship` model defines table relationships through foreign keys, highlighting the logical links between data.

- **Key fields**:
  - **Source table**: Table containing the foreign key.
  - **Destination table**: Table referenced by the foreign key.
  - **Source column**: Column acting as the foreign key.
  - **Destination column**: Column referenced by the foreign key.

- **Relationships**:
  - Connects two `SqlTable` entries (source and destination) and two `SqlColumn` entries (source and destination) to represent a foreign-key relationship.

## 2 - Utilizzo del Modello in ThothAI

In the ThothAI project, the `Relationship` model maps table connections during SQL generation. Main functions include:

- **Database schema retrieval**: Extracts table relationships to understand available data.
- **Schema string generation**: Converts relationship information into textual representations optimized for LLM prompts.

## 3 - Form di Amministrazione Associato

### 3.1 - RelationshipAdmin
The `Relationship` admin form lets you define and manage table relationships.

- **Features**:
  - Select source/destination tables and columns to define a relationship.
  - Update primary/foreign key fields on the involved columns.
  - Filter relationships by database or table.

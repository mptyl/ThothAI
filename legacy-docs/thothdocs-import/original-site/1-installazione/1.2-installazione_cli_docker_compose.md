# CLI Installation on Docker Compose (Single Node)

This guide explains how to install ThothAI on a single node (local machine or remote server) using the official CLI and Docker Compose. This is the standard mode for most non-cluster installations.

## 1. Prerequisites

*   **Python 3.9+** installed.
*   **uv** package manager installed (`curl -LsSf https://astral.sh/uv/install.sh | sh`).
*   **Docker Desktop** (or Docker Engine) active on the target machine.

## 2. CLI Installation

Create a folder for the project and install the CLI:

```bash
mkdir my-thothai
cd my-thothai
uv venv
source .venv/bin/activate  # (On Windows: .venv\Scripts\activate)
uv pip install thothai-cli
```

## 3. Initialization

Initialize the project for standard mode (Compose):

```bash
uv run thothai init
```

This command will download the basic `config.yml.local` file to the current directory.

## 4. Configuration

Modify `config.yml.local` with your settings:

```yaml
# Partial example of config.yml.local
llm:
  api_key: "sk-..." # Your OpenAI key

docker:
  network_name: "thoth-network"
  # Optional: Private Registry Configuration
  # image_registry: "registry.company.com"
  # registry_username: "user"
  # registry_password: "password"
```

### Registry Choice
*   **Docker Hub (Default)**: If you leave the registry fields commented, images will be downloaded from the public `tylconsulting` Docker Hub.
*   **Private Registry**: If your company uses a private registry (where you have pushed as described in Manual 2), uncomment and fill in the `image_registry`, `registry_username`, and `registry_password` fields.

## 5. Deploy

The CLI manages both local and remote deployment.

### Scenario A: Local Installation
To install on the current machine (where you ran `init`):

```bash
uv run thothai up
```
The command will configure volumes, network, and start containers. The interface will be available at `http://localhost:3040`.

### Scenario B: Installation on Remote Server
To install on a remote server reachable via SSH:

```bash
uv run thothai up --server ssh://user@remote-ip
```

The CLI:
1.  Will connect via SSH.
2.  Will copy necessary configurations.
3.  Will run `docker login` (if private registry is configured).
4.  Will start the application on the remote server.

### Verification
After deployment, you can check the status:

```bash
# Local
uv run thothai status

# Remote
uv run thothai status --server ssh://user@remote-ip

# Legacy Content

Historical or unsupported documentation is kept in the repository but excluded from the published MkDocs navigation.

## Archive Locations

- `legacy-docs/thothai-original/`: documentation that originally lived in `ThothAI/docs`
- `legacy-docs/thothdocs-import/`: imported `ThothDocs` pages that are no longer part of the public site

## What Was Archived

- source installation guides
- Docker Swarm guides
- Italian-only public pages
- roadmap or workflow pages that do not match the current public runtime contract
- older architecture notes superseded by the current SQL Generator pipeline documentation

## Non-Published Video Material

Video scripts remain versioned in the `thoth_docs` repository under `archive/video_scripts/`.
They are intentionally excluded from MkDocs and were not migrated into the public `ThothAI` site.
